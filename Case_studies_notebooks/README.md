# lncAPNet: Deciphering lncRNA–mRNA Connections in Patient Transcriptomic Data

---

## 📌 Pilots & Results

**lncAPNet** addresses the need for interpreting non-linear transcriptomic interactions in cancer types, validated across:

* **CLL** (Chronic Lymphocytic Leukemia)

* **PRAD** (Prostate Adenocarcinoma)

* **BRCA** (Breast Invasive Carcinoma)

---

## 💾 Data Availability

Data for case studies is available on Zenodo [10.5281/zenodo.20637947](https://zenodo.org/records/20637947). Download the lncAPNet_v3.zip (2.7 GB) for necessary data matrices and pre-computed network files.
